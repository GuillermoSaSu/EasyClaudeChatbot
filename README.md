# EasyClaudeChatbot
An easy project in Python that talks with Clause using the Antropic's API

## Steps to get started

1. **Install Python** (3.9 or higher) if you haven't already.

2. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Get an API key** at https://console.anthropic.com/settings/keys

4. **Set the API key as an environment variable:**

   On Mac/Linux:
   ```bash
   export ANTHROPIC_API_KEY="your-key-here"
   ```

   On Windows (PowerShell):
   ```powershell
   $env:ANTHROPIC_API_KEY="your-key-here"
   ```

5. **Run the chatbot:**
   ```bash
   python chatbot.py
   ```

6. Type `exit` to end the conversation.
